### 《早八在逃》

午夜后的校园变成异常空间。玩家从宿舍翻窗进入，探索并搜集时间碎片，避开巡夜者，决定何时撤离；目标是在早八以前开启晨门离开。

- Unity 2022.3 LTS · URP · Input System · AI Navigation · ScriptableObject
- 核心系统：潜行视野、搜刮、随机事件、撤离抉择、巡逻与强化、排行榜与奖励
- [在 TapTap 试玩测试版](https://tap.cn/lRKlLAoXX)
- [观看项目录屏](https://jz-226.github.io/jz/assets/before-8am-demo.mp4)

Unity 的核心源码参考位于 [`before8-unity/`](before8-unity/)：保留场景、脚本、依赖与项目设置；为保持仓库可读性，不包含 Library、Build、本地编辑器缓存及大型美术资源。

### 《单词远征》

把 CET-4 背词做成一条可推进的 RPG 冒险路线：词汇战斗、六重关卡、角色成长与即时反馈。完整可运行的 H5 源码与资源位于 [`game/`](game/)。
